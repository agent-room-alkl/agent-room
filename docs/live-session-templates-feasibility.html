Agent Room feasibility memo

Live Session Templates：把 AI 面试变成 Agent Room 的自然扩张

本方案整理 Codex 与 Claude 在 Agent Room 会议中的共同判断：AI 面试可行，但不应作为孤立 HR 功能加入。 更自然的方式是把它定义为第一个 Live Session Template，为后续 AI 教练、客户调研、销售资格、复盘主持等场景打基础。

结论：可做 建议：先做窄 demo 定位：structured live session 共识方：Codex + Claude

一句话结论

Agent Room 现在做的是 AI agents 之间的协作 session。加入 AI 面试后，产品扩张到 AI + 真人之间的 structured live session。 两者共用同一套骨架：room、roles、transcript、artifacts。新增能力是实时音视频和 voice agent，而不是把 Agent Room 改造成 HR SaaS。

因此，不建议把它命名为「AI Interview Feature」。建议命名为 Live Session Templates，其中 AI Interview 是第一个 template。

可行性判断

技术上可行 没有需要发明的新基础设施。核心是 WebRTC 视频房、实时语音 AI、Agent Room transcript/artifact 三者组合。
2-3 周 窄版 live interview demo 的现实预估。前提是先验证音频桥接链路，再做 UI 和报告。
中高切合 和协议层高度契合；和当前 dev-focused 首页文案契合较低，因此应放进 templates/scenarios。

推荐技术路线

  • 实时音视频层：使用 LiveKit / Daily / Agora 等成熟 WebRTC 服务，不自研 SFU。
  • 实时语音 agent：服务端 voice bot 作为房间 participant，接收候选人音频并输出 AI 语音。
  • Agent Room 层：继续负责房间、角色、转写、scorecard、artifact、报告和观察者视图。

最大技术风险

第一风险不是页面，而是音频桥接：候选人 audio track → realtime AI → synthesized audio track → 回到 WebRTC room。 因此第一周应该先 spike 这条链路，不要先投入过多 UI。

和当前 Agent Room 的切合度

层面 切合度 说明
协议层 很高 room、participants、roles、transcript、artifacts 天然适合面试记录、scorecard 和观察者协作。
产品抽象 高 只要抽象为 structured live session，AI 面试就是一个 template，而不是垂直产品分叉。
当前首页文案 较低 当前首页主叙事是 Claude / Cursor / Codex 的 dev collaboration。直接塞 HR 场景会模糊定位。
商业扩张 高 AI 面试可以成为 Live Session Templates 的第一个证明点，后续扩到 coaching、research、sales 等。

场景家族：Live Session Templates

以下场景都属于同一个家族：真人与 AI 在实时房间里完成结构化任务，并输出可签收 artifact。

场景 角色配置 输出 artifact 可行性
AI 面试 AI Interviewer + Human Candidate + Observer Scorecard、hire/pass 建议、证据摘录 首个 MVP
AI 教练 / 辅导 AI Coach + Human Learner 学习报告、下次目标、练习计划 高
AI 客户调研 AI Researcher + Customer Research brief、insights、quotes 高
AI 销售 / 售前 AI SDR + Prospect + Sales Observer Qualification report、需求摘要、下一步 中高
AI 法律/医疗 intake AI Intake + Patient/Client 结构化病例/案件摘要 可行但高合规
AI 模拟练习 AI Coach + Human Practitioner 反馈卡、改进建议、练习重点 高
AI 调解 / 主持 AI Facilitator + 2 Humans 决议记录、共识点、分歧点 中
AI 站会 / 复盘主持 AI Facilitator + Team Action items、timeline、owner list 高

AI Interview MVP：推荐范围

1. Candidate joins 浏览器打开 interview link，授权 mic/camera，无需安装 MCP。
2. Voice AI opens AI interviewer 用固定 prompt 语音开场。
3. Live conversation 候选人语音回答，可打断；AI 语音追问。
4. Transcript sync 候选人转写与 AI 回复实时进入 Agent Room。
5. Scorecard artifact 结束后生成简单 scorecard，作为 [RESULT] artifact。

Out of scope

排班、候选人 CRM、题库后台、权限隔离、长期录像保存、合规审计、多语言、自定义 voice、自定义 rubric UI。 这些都不进入第一版，避免把验证 demo 拖成完整 HR 系统。

推荐路线图

阶段 目标 交付物
Phase 0：Spec 统一产品抽象和边界 Live Session Templates spec、AI Interview MVP scope、技术 spike 计划
Phase 1：Audio bridge spike 验证最核心技术链路 Candidate audio in → realtime AI → AI voice out → WebRTC room
Phase 2：Interview demo 做出 10 分钟可演示 happy path 候选人加入页、实时 transcript、scorecard artifact、观察者视图
Phase 3：Template platform 把 AI 面试抽象成可复制模板 Prompt packs、artifact schemas、更多 templates，例如 coaching / research / sales

定位建议

  • 不要：把首页主标题改成 AI Interview 或 AI 招聘工具。
  • 不要：把第一版做成完整 HR SaaS。
  • 要：把 AI Interview 作为 Live Session Templates 的第一个 proof point。
  • 要：保留 Agent Room 的横向定位：AI agents 与 humans 在 room 里完成结构化 session，并输出 artifacts。
推荐对外说法：Agent Room now supports Live Session Templates: structured real-time sessions where humans and AI participants talk, collaborate, and produce signed-off artifacts.
